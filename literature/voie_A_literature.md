# Voie A — État de l'art : l'équation de ronde CPWI comme équation à une variable

*Bibliographie associée : `voie_A_refs.bib` (87 entrées ; 83 DOI résolus le 2026-09-18 (79 via Crossref, 4 DOI LIPIcs via doi.org), 4 prépublications arXiv sans DOI, signalées `DOI unverified`). Les clés `[xxx]` renvoient à ce fichier.*

## 0. Objet et cadrage

Le système de ronde `R(U',V';A,B) : U' = U A V U, V' = V B U V` sur `A_m × A_m` est, d'après la reformulation vérifiée par la coordination (m = 5 exhaustif, m = 6 sur 300 instances), **exactement** l'équation à une variable

    x · a · x² = c      dans K = A_m ≀ C_2 = (A_m × A_m) ⋊ C_2 ≤ S_{2m},

avec `x = (U,V)σ`, `a = (B,A)` dans le groupe de base, `c = (U',V')σ` dans la classe σ. Conséquences immédiates utiles pour la lecture de la littérature : (i) `a = 1` donne la racine cubique `x³ = c` ; (ii) `x⁻¹ c x = a x³`, donc une solution est une « racine cubique tordue » : `c` et `a x³` sont conjugués par `x` lui‑même ; (iii) par symétrie `x a x² = c ⇔ x⁻¹ c x⁻² = a` (`a` et `c` jouent des rôles duaux).

Trois régimes sont à distinguer, car la littérature ne les mélange jamais :

| Régime | Groupe | #variables | Forme du mot | Résultats connus |
|---|---|---|---|---|
| (F) groupe **fixe** | `G` constant | non borné (entrée) | longueur = entrée | Goldmann–Russell et suite (§2) |
| (S) **sous‑groupe** en entrée | `G = ⟨S⟩ ≤ S_n` par générateurs | 1 à k fixé | fixe ou entrée | appartenance, knapsack, type de cycle (§1, §3) |
| (W) **groupe entier** en entrée | `S_n`, `A_n`, `A_m ≀ C_2`, `n` = entrée | 1 (ou 2) | **fixe**, longueur 3 | racines, conjugaison seulement (§1) |

CPWI vit dans le régime (W). C'est le régime le moins étudié : nous n'avons trouvé **aucun** résultat (algorithme sous‑exponentiel ou dureté) sur une équation à une variable de forme fixe de longueur ≥ 3 lorsque le groupe est `S_n`/`A_n` avec `n` en entrée.

## 1. Équations à une variable avec constantes dans S_n / A_n (régime W)

**Racines `x^k = c`.** Polynomiales : `c` est une puissance `k`‑ième ssi sa structure cyclique se regroupe convenablement (un cycle de longueur `L` de `x` se scinde en `gcd(L,k)` cycles de longueur `L/gcd(L,k)` dans `x^k`) ; une racine se construit en recollant des cycles. Le dénombrement est classique : proportion de carrés `~ (2/(πn))^{1/2}` [blum1974], nombre d'éléments de chaque ordre [wilf1986], proportion de permutations admettant une racine `m`‑ième `~ c_m n^{-(1-φ(m)/m)}` [pouyanne2002] (donc `~ n^{-1/3}` pour les cubes), probabilités de racines [bona2000]. Le **nombre** de racines peut être exponentiel pour des `c` particuliers (les racines carrées de l'identité sont les involutions), mais vaut 1 en moyenne sur `c` uniforme. Pour `A_m ≀ C_2` : `x = (U,V)σ` donne `x³ = (UVU, VUV)σ`, donc le cas `a = 1` de la ronde est une racine cubique dans `S_{2m}`, polynomiale.

**Conjugaison et conjugaison tordue.** `x⁻¹ a x = c` se résout par types de cycles. La conjugaison tordue `x a φ(x)⁻¹ = c` [bogopolski2010] se ramène à la conjugaison ordinaire dans `S_n` puisque `Aut(S_n) = Inn(S_n)` (`n ≠ 6`). Dans le régime (S) au contraire, décider si `⟨S⟩` contient un élément d'un type de cycle donné (ou sans point fixe) est NP‑complet, déjà pour des 2‑groupes abéliens élémentaires [cameronwu2010, lubiw1981, lohreyrosowski2025] ; la dureté est portée par le sous‑groupe, non par la forme de l'équation. Pour le groupe entier la même question est triviale.

**« Quadratique » `x a x = c`.** Elle n'est pas plus dure que la racine carrée : `x a x = c ⇔ (xa)² = ca`, donc résoluble en temps polynomial, avec `#solutions = #√(ca)`. Plus généralement tout mot à une variable où `x` apparaît **deux fois** (`x a x b = c`, `x a x⁻¹ b = c`, `x² = c`) se réduit à racine carrée ou conjugaison : la longueur 2 est entièrement polynomiale. *Correction à l'énoncé de tâche : « quadratic » n'est pas un cas séparé.*

**Longueur 3 : `x a x² = c`, `x² a x = c`, `x a x b x = c`.** C'est la première longueur non résolue par les techniques ci‑dessus. Les substitutions `y = xa` etc. permutent ces formes entre elles (par ex. `x a x b x = c ⇔ y² g y = c a` avec `y = xa`, `g = a⁻¹b`) mais ne les réduisent pas à la longueur 2. Nous n'avons trouvé aucune publication traitant l'algorithmique de ces équations sur `S_n` avec `n` en entrée. Ce qui existe autour :

* *Mots avec constantes sur `S_n`* [schneider2023] : pour un mot `w ∈ F_r * S_n` « fort » (sans annulation des variables après suppression des constantes — c'est le cas de `x a x²`, de contenu `x³`) et assez court, l'image `w(S_n)` a un diamètre positif en métrique de Hamming normalisée, borné en fonction de la longueur ; tout self‑map d'un groupe simple fini est un mot avec constantes. Ce sont des résultats d'**image**, pas de fibres ni d'algorithme. Voir aussi [bradford2023, nitsche2022, klyachko2017, gordeev2018].
* *Équidistribution asymptotique des valeurs de mots avec constantes* [alekseev2025, arXiv] : les valeurs de `w(σ_1,…,σ_r)` pour des `σ_i` uniformes tendent vers l'uniforme quand `n → ∞`. Si les hypothèses couvrent `x a x²` (à vérifier dans la prépublication), cela dit que pour `a` fixé et `c` typique la fibre est de taille `Θ(1)` en moyenne — contraste avec `a = 1` où l'image (les cubes) est de densité `~ n^{-1/3}` : les constantes « mélangent ». Aucune conséquence algorithmique.
* *Équations à une variable dans les groupes libres* [lyndon1960, chiswell2000, bormotov2009] : solutions paramétriques, algorithme polynomial ; groupes infinis, technique (langages algébriques, longueur) sans analogue fini connu.
* *Produit en couronne* [ushakov2025, arXiv] : équations à une variable dans `Z_2 ≀ Z` (lamplighter) : décidables, complexité super‑exponentielle au pire, presque quadratique en cas générique. C'est le seul travail trouvé sur les équations à une variable dans un produit en couronne ; il exploite la structure de la base abélienne, absente ici (`A_m` simple).

**Implication pour CPWI.** La ronde est la plus petite équation à une variable hors du domaine polynomial connu. La contrainte nécessaire `ctype(a x³) = ctype(c)` (issue de `x⁻¹ c x = a x³`) et le cas `a = 1` polynomial suggèrent la voie « racine cubique + conjugaison » : énumérer les types de cycles possibles de `x³`… mais `a x³` dépend de `x`, et il n'existe pas de formule de comptage par caractères pour un mot avec constante non centrale.

## 2. Satisfiabilité d'équations sur groupes finis (régime F)

Toutes ces références fixent le groupe `G` et prennent l'équation (avec constantes, nombre de variables **non borné**) en entrée.

* [goldmann2002] : une équation `w_1⋯w_k = 1` : dans P pour `G` nilpotent, NP‑complète pour `G` non résoluble (donc pour `A_m`, `m ≥ 5`, et pour `A_m ≀ C_2`) ; systèmes : P ssi `G` abélien. La réduction (depuis SAT via programmes/NUDFA [barrington2000]) utilise `Θ(taille)` variables et un mot de longueur croissante.
* Résolubles non nilpotents : polynomialité pour des classes de longueur de Fitting 2 — nilpotent‑par‑nilpotent partiellement [horvath2011, horvath2015, horvath2011dmtcs, horvath2012a4], semipattern [foldvari2018, foldvari2020], algèbres supernilpotentes [kompatscher2018] ; équivalence coNP‑complète pour non résolubles [horvath2007, horvath2006, burris2005].
* Bornes inférieures conditionnelles : sous ETH, non dans P pour longueur de Fitting ≥ 4 et certains cas de longueur 3 [weiss2020] ; sous ETH, PolSat dans P **force** un sous‑groupe normal nilpotent à quotient nilpotent [idziak2022] (version journal ToCS 68 (2024) de arXiv:2010.11788) ; extension aux algèbres de Malcev [idziak2022stacs] ; caractérisation de ProgramSat en temps polynomial randomisé sous rETH + Constant Degree Hypothesis, PolSat pour une large classe, et classification de **ListPolSat** (chaque variable restreinte à un sous‑ensemble arbitraire) [idziak2022icalp] ; complexités intermédiaires (quasi‑polynomiales) [idziak2020, idziak2022b].

**Implication.** Pour un groupe fixe et **un nombre borné de variables**, toute équation se résout en `O(|G|^k)` = constante : la dureté de Goldmann–Russell est celle du nombre de variables. Elle ne dit rien sur la ronde (une variable, forme fixe, `|G| = (m!/2)²·2` en entrée succincte). Symétriquement, si `G` est donné par sa table de Cayley, une équation à une variable est triviale (`|G|` essais, polynomial en la taille de l'entrée) : le régime (W) n'est intéressant que parce que `S_n` est codé en `O(n log n)` bits pour `n!` éléments. La variante ListPolSat de [idziak2022icalp] est la plus proche formellement (contrainte `x ∈ (base)·σ`) mais reste en régime F.

## 3. Appartenance, knapsack, sous‑ensembles rationnels (régime S)

* Appartenance à un sous‑groupe `⟨S⟩ ≤ S_n` : polynomiale (Schreier–Sims) [sims1970, furst1980, knuth1991, seress2003] ; dans NP pour les groupes boîte noire [babai1984].
* [lohrey2022mfcs, lohrey2022] (MFCS 2022 ; J. Algebra 2025) : pour des permutations en entrée (`m` en unaire), **subset sum** (`a = a_1^{e_1}⋯a_n^{e_n}`, `e_i ∈ {0,1}`), **knapsack** (`e_i ∈ ℕ`) et **appartenance à un sous‑ensemble rationnel** (donné par un automate sur les générateurs) sont NP‑complets ; le knapsack est NP‑complet **dès `n = 3` fixé**, i.e. l'appartenance à un produit de trois groupes cycliques `⟨a_1⟩⟨a_2⟩⟨a_3⟩` est NP‑complète, ce qui affine Luks (produit `GHG` de trois sous‑groupes abéliens) [luks1993] ; l'appartenance « context‑free » est PSPACE‑complète ; les bornes supérieures valent pour les groupes boîte noire. Réductions depuis 1‑in‑3‑SAT (X3HS) codé dans la structure cyclique des `a_i`.
* Factorisation : longueur minimale d'un mot en générateurs NP‑dure [even1981], PSPACE‑complète [jerrum1985] ; problèmes de distance/poids NP‑complets [buchheim2009, cameronwu2010, arvind2013].

**Implication.** Le 3‑knapsack est une équation de forme fixe à trois variables **contraintes à des sous‑groupes cycliques** ; c'est la dureté la plus proche de la ronde en régime « groupe entier en entrée ». Mais (i) la dureté est au pire cas, avec des constantes `a_i` adversariales à petits cycles, alors que CPWI a des constantes aléatoires et une inconnue libre dans une classe entière ; (ii) `{x a x² : x ∈ K}` n'est pas un sous‑ensemble rationnel : aucun de ces résultats ne s'applique. La technique de réduction (coder X3HS dans les types de cycles) est en revanche le gabarit naturel pour tenter une preuve de NP‑dureté au pire cas de `x a x² = c` avec `a` adversarial.

## 4. Applications de mots sur S_n / A_n et leurs fibres (régime W, sans constantes)

* Waring non commutatif : pour `w ≠ 1`, `w(G)³ = G` [shalev2009, larsen2009], `w_1(G) w_2(G) = G` pour `G` simple fini assez grand [larsen2011] ; conjecture d'Ore (commutateur surjectif) [liebeck2010] ; puissances [nikolov2011] ; images pouvant être arbitrairement petites [lubotzky2014] ; synthèse [shalev2013].
* Fibres : pour `w ∈ F_d` non trivial il existe `ε(w) > 0` avec `|w⁻¹(g)| ≤ |G|^{d-ε}` pour tout `G` simple fini et tout `g` [larsen2012] ; commutateur presque mesure‑préservante, `#{[x,y] = c} ≈ |G|` [garion2009] ; équidistribution probabiliste de `w_1 w_2` [larsen2019] ; fibres et facteurs de composition [bors2017].
* Mesures de mots sur `S_n` : `w` induit asymptotiquement l'uniforme ssi `w` est primitif [puder2014, puder2015] ; développement en `1/n` de `E[fix w(σ)]` [hanany2023] ; version avec constantes [alekseev2025].

**Usage algorithmique.** Aucun : ces résultats reposent sur la théorie des caractères (formule de Frobenius `#{w = c} = |G| Σ_χ …` pour les mots sans constantes) et sur des estimations de degrés de caractères ; la somme porte sur `p(n)` caractères de `S_n` (exponentiel) et ne fournit ni algorithme ni certificat. Pour la ronde, ils fixent l'**ordre de grandeur** attendu : le système à deux inconnues et deux équations (`d = 2`, deux mots) a une fibre générique `Θ(1)` — cohérent avec l'élimination `V = A⁻¹U⁻¹U'U⁻¹` et les fibres observées — et la borne `|G|^{d-ε}` exclut des fibres géantes sauf pour des `c` exceptionnels. Ils ne disent rien sur la **recherche** d'un point de la fibre.

## 5. Cryptanalyses ayant inversé une ronde de groupe en résolvant un mot court

**Hachages de Cayley (Tillich–Zémor, Petit–Quisquater, Grassl et al.).** `H(m_1…m_k) = A_{m_1}⋯A_{m_k}` dans `SL_2(F_{2^n})` [tillich1994, zemor1994] ; préimage = **factorisation** d'une matrice en mot dans deux générateurs [petit2013]. Les attaques exploitent la représentation fidèle 2×2 sur un anneau euclidien : on relève dans `SL_2(F_2[X])` où l'algorithme d'Euclide sur les entrées polynomiales factorise ; [grassl2011] obtient des **collisions** (mots palindromes/structure euclidienne), [petit2010] des **préimages**, [petit2008] casse LPS/Morgenstern par relèvement à `SL_2(ℤ)`, [petit2014, bromberg2017] généralisent. Leçon : la dureté s'effondre dès qu'une représentation linéaire de petite dimension sur un anneau à division euclidienne existe. `S_n` n'a pas de représentation fidèle de dimension `< n-1` et la représentation par matrices de permutation rend `U A V U = U'` **quadratique** en `U` (cubique dans la forme à une variable), sans structure euclidienne.

**Attaques par longueur (Hughes–Tannenbaum, Garber–Kaplan–Teicher–Tsaban–Vishne, Myasnikov–Shpilrain–Ushakov, Myasnikov–Ushakov, Ruinskiy–Shamir–Tsaban).** Pour résoudre `x a x⁻¹ = c` ou `x a y = c` dans un groupe de tresses ou de Thompson, on descend gloutonnement une fonction de longueur : multiplier `c` par le bon générateur réduit la longueur normale [hughes2002, garber2006, myasnikov2005, myasnikov2007, ruinskiy2007]. Cela suppose un graphe de Cayley « à gradient » (grande croissance, géodésiques stables). Dans `A_m` avec constantes aléatoires, le graphe de Cayley est un expanseur de diamètre `O(m)` et aucune longueur naturelle (nombre de cycles, points déplacés) ne décroît le long d'une solution : la technique n'a pas d'analogue direct.

**Cheon–Jun (Diffie–Hellman sur tresses) et linéarisation (Shpilrain, Tsaban, Ben‑Zvi–Kalka–Tsaban).** [cheon2003] résout le problème DH‑conjugaison en temps polynomial : dans la représentation de Lawrence–Krammer (dimension `n(n-1)/2`), la contrainte `x a x⁻¹ = c` avec `x` dans un sous‑groupe commutant devient un système **linéaire**. Généralisations : centralisateur linéaire [tsaban2015], espaces algébriques [benzvi2018], Stickel [shpilrain2008], décomposition `x a y = c` [shpilrain2006]. Toutes exigent que le secret intervienne linéairement dans une représentation fidèle. Pour la ronde, `x a x² = c` est de degré 3 en `x` ; la seule linéarisation évidente (`y = x²`, puis `x a y = c` bilinéaire) réintroduit la contrainte quadratique `y = x²`. C'est la question à trancher côté algèbre : existe‑t‑il un changement de variable rendant la ronde linéaire dans une représentation de dimension `poly(m)` ?

**Fonctions à sens unique antérieures sur groupes de permutations.** Les signatures logarithmiques / PGM de Magliveras–Stinson–van Trung [magliveras2002] sont l'ancêtre direct d'une OWF sur `S_n` ; MST3 (2‑groupes de Suzuki) a été cassé en exploitant la structure du groupe choisi [blackburn2009]. Leçon transférable : la sécurité doit résister à la **structure** du groupe, pas seulement à sa taille.

## 6. Ouvert d'après la littérature (Open according to the literature)

1. **Complexité de `x a x² = c` sur `S_n`/`A_n`/`A_m ≀ C_2`, `n` en entrée.** Aucun algorithme meilleur que la force brute `|G|` ou la propagation de contraintes mesurée (`~2^{1.98m}`), et aucune dureté (NP, ETH) : la longueur 3 à une variable est exactement la frontière entre le polynomial connu (longueur ≤ 2 : racines, conjugaison, `x a x = c`) et l'inconnu. Question précise : existe‑t‑il `f(m) = 2^{o(m)}` pour la racine cubique tordue `x⁻¹ c x = a x³` ?
2. **Cas spéciaux résolubles.** `a = 1` (racine cubique) est polynomial ; la littérature ne traite pas `a` central dans le centralisateur de `c`, `a` à petit support, `a` involutif, ni `c` à type de cycle contraint. À tester algébriquement.
3. **Dureté au pire cas.** Une réduction à la manière de [lohrey2022mfcs] (codage de X3HS dans les cycles de `a`) prouverait la NP‑dureté de la forme fixe pour `a` adversarial ; ce serait le premier résultat de dureté pour une équation à **une** variable de forme fixe en régime (W). Cela n'impliquerait pas la dureté moyenne requise par CPWI.
4. **Dureté en moyenne.** Aucune référence n'établit de dureté moyenne pour une équation sur groupe ; les seuls énoncés « moyens » sont des équidistributions ([garion2009, puder2015, alekseev2025]) qui décrivent la distribution des sorties, pas la difficulté d'inversion.
5. **Comptage des fibres avec constantes.** Pas de formule de caractères pour `x a x² = c` (constante non centrale) ; seule l'équidistribution asymptotique [alekseev2025] (hypothèses à vérifier pour ce mot) donne la taille typique `Θ(1)`.
6. **Linéarisation.** Aucun résultat n'exclut une représentation de dimension `poly(m)` dans laquelle la ronde devient linéaire ou de degré 2 résoluble ; les attaques de type Cheon–Jun / Tsaban sont le test à faire passer avant toute revendication de sécurité.
7. **Positionnement.** L'écart entre le régime (F) de Goldmann–Russell (groupe fixe, variables nombreuses) et le régime (W) de CPWI (groupe en entrée, une variable, forme fixe) n'est couvert par aucun théorème ; il constitue en lui‑même une question de complexité à formuler dans le mémo.
